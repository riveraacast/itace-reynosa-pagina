# Proyecto ITACE

Esta es una página web que estoy realizando sobre el ITACE Plantel Reynosa.

En ella quiero mostrar información de la escuela, sus especialidades y algunas de las actividades que se realizan. También agregué imágenes, videos y diferentes secciones para que la página no se vea tan sencilla.

Para hacerla utilicé HTML, CSS y JavaScript. Fui agregando los diseños, colores y funciones para darle mi propio estilo.

Algunas de las cosas que tiene son:
- Información de la escuela.
- Especialidades.
- Instalaciones.
- Vida estudiantil.
- Proyectos de los alumnos.
- Noticias y eventos.
- Directorio de maestros.
- Galería y contenido multimedia.

Este proyecto forma parte de mis trabajos escolares y todavía estoy trabajando en algunos detalles.
